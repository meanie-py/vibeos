# ieframe hosts the page through CoCreateInstance(CLSID_HTMLDocument): a registry edge the
# import walk cannot see.
reactos/system32/mshtml.dll
# control.exe runs every applet as `rundll32 shell32.dll,Control_RunDLL x.cpl`: a process,
# not an import. Without it all twelve cpl-* appstorm entries opened no window on arm64.
reactos/system32/rundll32.exe
# ...and once rundll32 exists, explorer's startup really runs `rundll32 iernonce.dll
# RunOnceExProcess` and WAITS for it before the StartUp folder. Without iernonce, rundll32
# sat on its load-failure box and nothing in StartUp (appstorm included) ever launched.
reactos/system32/iernonce.dll
# COM proxy/stubs are found through HKCR\Interface\{iid}\ProxyStubClsid32, never an import:
# without actxprxy ole32 could not marshal ieframe's interfaces, CLSID_InternetExplorer
# failed to register (E_NOINTERFACE) and iexplore then faulted on the NULL it got back.
reactos/system32/actxprxy.dll
# sol/spider load their card faces from cards.dll at run time.
