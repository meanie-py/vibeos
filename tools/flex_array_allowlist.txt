# Format: [@arch[,arch]] <crate>: <symbol>      # rationale
#
# The symbol is the ARCH-NEUTRAL name the scanner prints: no i386 `_` decoration, no
# `@N` stdcall suffix, no `17h<hash>E` legacy-mangling hash, no `.llvm.<n>` ThinLTO
# suffix. An unscoped entry applies to every arch; `@amd64,arm64` limits it to those.
# Scope an entry to the arches where the site EXISTS, because a stale entry fails the
# lint on the arch where it went stale.
#
# An entry here is a claim that the bounds check is CORRECT and must stay. It is not a
# deferral -- deferred work belongs in the roadmap, not in a file that silences a gate.
# Every entry names the evidence for both grading tests: does the C over-allocate, and is
# the declared length a LITERAL 1.
#
# A stale entry (one that no longer matches any finding) is reported as an error rather
# than ignored: it means either the site was fixed and the entry should go, or the reader
# stopped seeing it and the gate has quietly lost coverage.
