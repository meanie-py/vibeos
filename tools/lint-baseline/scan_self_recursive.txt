# scan_self_recursive baseline — PRE-EXISTING infinite self-jump functions.
#
# A function whose FIRST instruction jumps to its own entry spins the CPU forever:
# no bugcheck, no serial output, no panic. Every entry below is a real silent-hang
# landmine that predates the lint (2026-07-12). They are TRACKED AND OWED, not
# accepted — `--check` fails on anything NOT listed here, so a NEW self-recursion
# (like bootvid's memcpy/memset, field manual §9.60) is caught immediately.
#
# 2026-09-05: the exp2/exp2f/exp2l debt below is PAID and its 26 entries are gone —
# beepmidi, calc, dsound, the 22 d3dx9_*, and ucrtbase's pair. The note used to read
# "needs -fno-builtin-exp2 on those TUs (or a real impl)"; the actual fix was one
# word. `sdk/lib/crt/math/exp2.c` and `exp2f.c` are
# `{ static const T TWO = 2; return pow(TWO, x); }` with a comment claiming the
# `static const` stops clang folding the pow call back into exp2. It does not —
# constant propagation reads straight through it — so both compiled to a single
# branch-to-self. `static const volatile` forces a real load, leaving no
# compile-time 2 to fold, and all three arches come back clean.
#
# What surfaced it is worth keeping: scan_ud2's driver sweep filters on
# `rust_begin_unwind` and so only inspects Rust-CONTAINING binaries. ucrtbase.dll
# had no Rust until the msvcrt_shared cohab landed, so in two years that sweep had
# never once looked at it. THIS lint saw the spins the whole time and had them
# baselined; nothing acted on it until a second tool reported the same fact as new.
#
# Remaining debt (owed, not this lane):
#   classpnp KeRaiseIrql/KeLowerIrql/IoWMIDeviceObjectToProviderId
#                     — local stubs shadowing the ntoskrnl imports; hang if called.
#   ftfd rust_begin_unwind — a `#[panic_handler]` written `loop {}`: a panic that
#                       hangs SILENTLY. Should adopt panic-common (prints + bugchecks).
#   cdrom abort       — abort() stub written as a spin.
#   ntkrnlmp xHalHaltSystem — SANCTIONED, not debt: the HAL-dispatch halt
#                       fallback IS "spin forever" by contract (C: while(TRUE);
#                       fstub-rust halstub.rs `loop {}`). Appears only in the
#                       SMP-kernel sibling binary (ntkrnlmp.exe, built via
#                       --smp-kernel); same fn in ntoskrnl.exe doesn't fold to
#                       a first-insn self-jump there. KEPT even though an ordinary
#                       3-arch sweep does not produce that binary — dropping it
#                       would fail the next --smp-kernel build.
#
