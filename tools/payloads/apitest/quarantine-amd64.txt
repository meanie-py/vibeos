# So the discriminator is not "did the child crash" but "did the SWEEP move

# the child completes, the parent never returns from collecting it — most
# likely sweep.c's pipe pump, since a grandchild inheriting the write end keeps
# the pipe from ever reaching EOF (these subtests open sockets and talk to
# services). That is an inference from the shape, not something observed.
