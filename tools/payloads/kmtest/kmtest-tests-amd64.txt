# WAS QUARANTINED 2026-07-10 (BUGCHECK 0x1E, "expected-fail until an async-exceptions
# story exists; not an OS bug"). UN-QUARANTINED 2026-07-25: 33 pass / 0 fail.
# The old note named the exact fix and then declared it unreachable — the missing
# thing really was -fasync-exceptions, and turning it on is a two-line build change.
# Clang's default is a CALLS-ONLY exception model: it assumes instructions can't
# fault, so a __try whose body holds a faulting *instruction* rather than a *call*
# gets an EMPTY scope table and -O2 then DELETES the __except as unreachable. This
# test does `(void)*(volatile CHAR *)NULL` directly in the body, so its handler was
# compiled out of existence and the AV escaped to the kernel. Measured: the flag adds
# exactly 3 protected regions to RtlException.c — matching its 3 in-body fault sites.
